# Interview prompts

The active structured-decision prompt is [assigned_decision.txt](src/rehearse_ai/prompts/assigned_decision.txt); the active terminal prompt is [assigned_closing.txt](src/rehearse_ai/prompts/assigned_closing.txt). These files are loaded directly at runtime and are authoritative. There is no separately copied prompt text to drift.

The decision input includes the immutable assigned blueprint, exact current question, topic and follow-up guidance, candidate-specific focus areas, answers by question, last delivered/interrupted prompt and corrected session memory. Candidate speech and memory are untrusted content. The model proposes `advance`, `follow_up`, `nudge`, `wait`, `feedback_request`, `off_topic`, or `coach_identity` as validated structured output. It may also propose `covered_future_questions` with an exact quote from a collected answer; Python validates the citation and records the source turn before omitting a redundant later question. Python enforces order, required coverage, probe counts and allowed text. Explicit spoken stop, repeat, skip and correction handling precede ordinary inference. A feedback request is declined and does not consume a probe. The closing prompt asks only for a short professional sign-off without assessment, scores, suggested answers or outcome promises.

The previous practice-coach prompt files (`opening_ack.txt`, `decision.txt`, `feedback.txt`, `early_feedback.txt`) remain in the package for historical regression compatibility but are not selected by the assigned-interview HTTP path. `tts_style.txt` remains the existing voice-shaping instruction. The earlier [recorded take-home session](https://www.loom.com/share/928bba7d68ec4174856488a0ed2e1bb7) involved fixed project questions and coaching feedback; it is not evidence of the new prompt's behaviour. No real-model evaluation of assigned-interview conversational quality or microphone session has been completed. In particular, mocked routing tests establish controller limits, not the relevance or naturalness of generated probes.
