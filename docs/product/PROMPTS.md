# Interview prompts

## Live interview

The active assigned-interview decision prompt is [assigned_decision.txt](../../backend/src/rehearse_ai/prompts/assigned_decision.txt). This file is loaded at runtime and remains authoritative. `tts_style.txt` is the existing voice-shaping instruction.

Each decision receives a **bounded context**, not the plan: `interview_context` (title, purpose, style), `current_question` (the exact question, topic and its own follow-up guidance), `remaining_topics` (short topic labels of later unasked questions, used only to recognise earlier coverage), clipped `prior_answers`, the answer so far, `latest_candidate_turn`, corrected `session_memory` and overlays, `last_delivered_prompt`, `interrupted_prompt`, `candidate_focus_areas`, `remaining_follow_ups` and `time_pressure` (`normal`, `tight`, `exhausted`). Future question text and guidance, the grounding evidence and notes, and the administrator's private instructions are not sent. Candidate speech and memory are untrusted content. The model proposes a validated action; Python enforces order, required coverage, probe counts, the time budget and permitted text. A proposed covered future question requires an exact quote from the latest turn, which Python validates. Clear controls are recognised **before** inference by `backend/src/rehearse_ai/interview/controls.py` and never reach the model: ending (which outranks feedback or anything else in the same turn; a bare "I'm done" is clarified, and negations such as "don't end the interview" are preserved), repeat, restart or go-back (declined honestly), "I don't understand" (a repeat), feedback and process questions (fixed, bounded replies), and "I don't know", "I haven't used it" or a refusal (recorded as the answer, then the interview moves on; the whole turn is kept, so a mixed answer keeps its useful part). Spoken corrections and skips are handled as before.

The **closing is fixed text, not a prompt**: "That concludes the interview. Thank you for your time, {name}." (or, for an early end, "Thank you for your time, {name}. We'll end the interview here."). It makes no claim about hiring, contact or outcomes, and a model cannot add one. `assigned_closing.txt` was removed.

This reduction limits what the model is *given*. It is not a guarantee about what it *says*: spoken text is checked only for length, question count and (for the closing) feedback vocabulary. Follow-up guidance for the current question can still influence a spoken follow-up.

## Plan preparation

[plan_prepare.txt](../../backend/src/rehearse_ai/prompts/plan_prepare.txt) turns the résumé, job description, private instructions and duration into a structured plan (structured-output schema in `backend/src/rehearse_ai/plans/preparation.py`). [plan_revise.txt](../../backend/src/rehearse_ai/prompts/plan_revise.txt) applies one natural-language change and returns the complete plan. Documents, instructions and requests are untrusted data. Rules include: no invented experience, résumé-based questions must carry a verbatim résumé span, no protected-characteristic questions, no scoring or hiring guidance, closing as a tone note without outcome promises. The output is validated in Python and is never trusted because the prompt says so. The prompts are versioned with the application; the digest stored on each record covers every file in `backend/src/rehearse_ai/prompts/`.

## Historical practice prompts

`opening_ack.txt` is now used live: after the candidate's reply to the greeting, one short, neutral acknowledgement (its only input is the candidate's reply; the confirmed name appears only in a Python greeting template, never in a prompt). The output is validated and falls back to a fixed neutral line. The older practice-coach prompts (`decision.txt`, `feedback.txt`, `early_feedback.txt`) and the code that used them were removed in the structural cleanup: no route could reach them, because starting an attempt requires an assigned interview plan. They remain in Git history. The earlier [recorded take-home session](https://www.loom.com/share/928bba7d68ec4174856488a0ed2e1bb7) used fixed project questions and coaching feedback; it is historical evidence, not a current prompt evaluation. No real-model evaluation of assigned-interview *conversation* quality or microphone session has been completed; mocked routing tests establish limits, not naturalness. Plan-preparation checks with a real model are recorded in [PLAN_PREPARATION_CHECKS.md](../testing/PLAN_PREPARATION_CHECKS.md).
